GPC Visual Confirmation
========================

The GPC module provides a block that displays the viewer's Global Privacy
Control settings from the browser they are currently using.

This block has several options:
* Include GPC link: yes, no.
* Bakground color: none, white, and black
* Special Positioning: none, top of viewport, and bottom of viewport.

Note, where you place the block on the page is not important if you choose one
of the special positioning options.


Installation
------------

- Install this module using the official Backdrop CMS instructions at
  https://docs.backdropcms.org/documentation/extend-with-modules.

- Select any Layout from Admin > Structure > Layouts (admin/structure/layouts)
  and add the 'GPC Visual Confirmation' block to the Layout.

- Adjust block settings as desired.
